# Security policy

Reef is self-hosted software that holds source code and credentials, so we treat security
reports as the highest-priority issues.

## Reporting a vulnerability

Please do not open a public issue for a security problem. Use GitHub's private vulnerability
reporting on this repository ("Security" tab, "Report a vulnerability"), which reaches the
maintainers directly. Include the version (`reef version`), how to reproduce, and the impact
you see. You will get an acknowledgement within a few days and a fix or mitigation as soon as
one is ready; credit is given in the release notes unless you prefer otherwise.

## Supported versions

Only the latest release receives security fixes. Upgrade before reporting if you are behind.
